# Диагностический holdout с исправленными RFM

Пересчёт старых аналитических ячеек `RetailHero_AB_Uplift.ipynb` на 05.11.2026
с `final_stats` версии `retailhero_receipt_total_once_v2` (seed=42,
train/test=70/30, стратификация по treatment × target). Это **повторное
использование ранее просмотренного holdout**, не независимое подтверждение.

- A/B-эффект на 200 039 клиентах: +3,323 п. п., 95% ДИ [2,898; 3,748].
- Uplift топ-10% на 60 012 клиентах holdout: +6,205 п. п.
- Оценка по всему holdout: +3,321 п. п.
- Параметрический bootstrap старого ноутбука использует стандартизованную
  базовую оценку, поэтому его точечный gain +2,915 п. п. отличается от
  простой разности 6,205−3,321=2,884 п. п.; условный 95% ДИ
  [+0,567; +5,335] п. п.
- Число итераций двух моделей: 238 и 143 (early stopping).

Таблицы `ab_results.csv`, `segments.csv`, `interactions.csv`,
`uplift_topk.csv` и `uplift_deciles.csv` повторно вычислены скриптом аудита,
который исполняет аналитические ячейки с явно заданным исправленным RFM.
Каноническая оценка таргетинга для CV и основного README —
**3-fold OOF** в `../crossfit_2026-11-05_corrected`, а не эта проверка.
